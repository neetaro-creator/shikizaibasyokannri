# 積載資器材 3D ビューア

信楽分署の車両 4 台(信楽タンク1・信楽ポンプ1・信楽指揮1・信楽救急1)の積載資器材を、スマホ・PC から探せるウェブアプリです。

- **検索**:品名・通称で探す。ひらがな・カタカナ・半角全角の違いは気にしなくてよい。
- **探す**:名前が出てこないときは、分類の一覧か、車両の場所から中身を見る。
- **車両**:3D で積載場所が光る。場所を押すと中身の一覧が出る。
- **総数**:資器材ごとの全車合計(カラビナが全部で何個か、など)。

一度開いた端末では、電波がなくても使えます(ホーム画面に追加するとアプリのように開けます)。

## データの直し方

正本は `data/` の CSV です。GitHub の画面でファイルを開き、鉛筆ボタンで編集して保存(コミット)すれば、自動で再公開されます。

| ファイル | 中身 |
|---|---|
| `vehicles.csv` | 車両。`model` に 3D モデルのパス |
| `locations.csv` | 積載場所。`hotspot` は 3D 上の箱の位置(空なら自動配置) |
| `items.csv` | 資器材。`aliases` に通称を `;` 区切りで(例:`からびな;ビナ`) |
| `stock.csv` | どの資器材がどの場所に何個。数でない場合(適量・一式など)は `qty` を空にして `qty_note` に書く |

- 存在しない `item_id` / `location_id` を書くと公開処理が止まり、ファイル名と行番号が表示されます。
- `items.csv` の `aliases` には、漢字の品名のひらがな読みを自動で入れてあります(読み違いは直してください)。
- `data/review.csv` は、点検表からの初回変換で自信がなかった行の一覧です。`sheet2_only` は救急1の点検表の別シートにだけ載っている品で、今の積載に含めるか確認が必要です。実物と照合して CSV を直してください(照合後は削除して構いません)。

点検表(Excel)が改訂されたときは、新しい Excel を渡してもらえれば差分を CSV に反映します。初回変換のスクリプトは `tools/import_xlsx.py`(列の配置は `tools/import_config.json`)。

## 3D モデル

車両の 3D は写真をもとにコードで組んだ簡易モデルです(スキャンは使いません)。

- 信楽ポンプ1:`src/three/models/pump.ts`、信楽タンク1:`src/three/models/tank.ts`。シャッター・収納の位置と、点検表の場所名との対応もそれぞれのファイルにあります。共通の部品は `kit.ts`。
- 指揮1・救急1は箱を組んだ仮モデル(`src/three/placeholder.ts`)。写真をもらえれば同じ作りで起こします。
- 光る箱の位置は、`locations.csv` の `hotspot` 欄 > 車両モデルの対応表 > 自動配置 の順で決まります。
- `#/vehicle/pump1?align=1` を開くと位置合わせモードになり、箱を動かして `hotspot` 欄用の文字列を得られます。

## 開発

```
npm ci
npm run dev          # 開発サーバー
npm test             # 単体テスト
npm run e2e          # 画面テスト(Playwright)
python3 -m pytest tools   # 取り込みスクリプトのテスト
```

`main` ブランチに入ると GitHub Actions がビルドして GitHub Pages に公開します(リポジトリ設定の Pages で「GitHub Actions」を選ぶ必要あり)。
